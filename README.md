# Climate & Environment Data Analysis

This repository contains the code and data used for my CSE 163 final
project analyzing global temperature anomalies, carbon dioxide emissions,
and recent global weather observations.

## Project Files

- `eda.py` — Main runnable program. Loads the three datasets, runs the
  analysis, saves summary tables and statistics, and generates all project
  visualizations.
- `data_processing.py` — Contains functions for loading, cleaning,
  reshaping, summarizing, merging, and statistically analyzing the datasets.
- `visualizations.py` — Contains all plotting functions used to generate the
  figures included in the report.
- `test_data_processing.py` — Contains tests for the data-processing,
  merging, summary, slope, and statistical-testing functions.
- `requirements.txt` — Lists the Python packages needed to run and check the
  project.
- `data/` — Contains the datasets required by the program, except for the
  Global Weather Repository CSV described below.
- `figures/` — Contains figures generated by `eda.py`.
- `outputs/` — Contains summary CSV files and the text summary generated by
  `eda.py`.

## Required Data

The program expects these three files to be present inside the `data`
directory:

```text
data/
├── NASA Global Means.csv
├── GlobalWeatherRepository.csv
└── OWID_CB_WIDEF.csv
```

The repository includes:

- `NASA Global Means.csv`
- `OWID_CB_WIDEF.csv`

`GlobalWeatherRepository.csv` is not stored directly in this repository
because of its file size. To reproduce the full analysis, download the
Global Weather Repository dataset from its original source and place the
CSV file in the `data` directory using the exact filename:

```text
GlobalWeatherRepository.csv
```

No other path changes are needed.

The three datasets used in the project are:

1. NASA GISTEMP global temperature data
2. Global Weather Repository data
3. Our World in Data carbon dioxide and greenhouse-gas emissions data

## Python Setup

This project was written in Python 3.

From the root directory of the repository, install the required packages:

```bash
python -m pip install -r requirements.txt
```

The required packages are:

- `pandas`
- `numpy`
- `matplotlib`
- `scipy`
- `flake8`

## Running the Tests

From the root directory of the repository, run:

```bash
python test_data_processing.py
```

A successful test run prints:

```text
All tests passed!
```

The testing program uses small manually constructed DataFrames with known
results to verify the project's cleaning, reshaping, merging, aggregation,
slope, and statistical-testing functions.

## Running the Analysis

Before running the full analysis, make sure all three required CSV files are
inside the `data` directory.

Then run:

```bash
python eda.py
```

A successful run prints:

```text
Analysis complete.
Figures saved in: ...
Summary files saved in: ...
```

The program automatically creates the `figures` and `outputs` directories
if they do not already exist.

## Generated Figures

Running `eda.py` generates:

```text
figures/
├── nasa_annual_temperature.png
├── nasa_seasonal_temperature.png
├── co2_world.png
├── co2_countries.png
├── weather_monthly_temperature.png
├── weather_temperature_precipitation.png
├── combined_temperature_co2.png
└── country_co2_weather.png
```

These figures are generated programmatically by `visualizations.py` and are
used in the final project report.

## Generated Output Files

Running `eda.py` also generates summary and merged data files including:

```text
outputs/
├── nasa_summary.csv
├── weather_summary.csv
├── world_co2_summary.csv
├── monthly_weather.csv
├── temperature_co2_merged.csv
├── country_co2_weather.csv
└── eda_summary.txt
```

`eda_summary.txt` contains several key numerical results used in the report,
including:

- temperature trend slopes for 1950–1999 and 2000–2024
- the correlation between global temperature anomaly and world CO2 emissions
- mean temperature anomalies for the two time periods
- the one-sided Welch t-test statistic and p-value
- the number of countries included in the CO2-weather merge

## Code Quality Check

The submitted Python files pass `flake8`.

To reproduce the code-quality check, run:

```bash
python -m flake8 eda.py data_processing.py visualizations.py test_data_processing.py
```

A successful `flake8` run produces no output.

## Reproducing the Project Results

Starting from a fresh copy of this repository:

1. Download or clone the repository.
2. Download `GlobalWeatherRepository.csv` from the original Global Weather
   Repository source.
3. Place `GlobalWeatherRepository.csv` inside the repository's `data/`
   directory.
4. Confirm that `data/` contains all three required CSV files.
5. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Run the tests:

   ```bash
   python test_data_processing.py
   ```

7. Run the full analysis:

   ```bash
   python eda.py
   ```

8. Check `figures/` for the generated visualizations and `outputs/` for the
   generated numerical and tabular results.
9. Optionally run the code-quality check:

   ```bash
   python -m flake8 eda.py data_processing.py visualizations.py test_data_processing.py
   ```

No manual changes to relative paths are required when these commands are run
from the repository root.
